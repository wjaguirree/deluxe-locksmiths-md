Commercial Lock Rekeying in Hockessin - common questions

How does commercial rekeying work for a shop or office in Hockessin?

We remove the cylinders or re-pin them so the old keys stop working and new keys take over. The existing lock hardware stays in place unless we find a worn or damaged part. It's a practical way to reset access after staff changes, a lost key, or a security concern.

What should we have ready before you come out to rekey our building?

A simple door list helps: which entrances, offices, storage rooms, and outbuildings need to be changed. It also helps to know how many keys should keep working after the job. If your lock set uses a master key system, tell us that up front so we can plan the rekey correctly.

What's the risk if a former employee still has an old key?

That's one of the main reasons businesses rekey. An old key may still open one door or several if the building uses a master system. Rekeying closes that gap without forcing you to replace every lock. If you're unsure who has copies, we can still reset the locks and start fresh.

Should we rekey all the locks or just change the one entrance door?

It depends on how the business is set up. A single-door rekey can solve a narrow problem, but many Hockessin businesses do better with a broader reset so side doors, offices, and storage areas match the same access plan. We'll look at how the building is used and help you decide.

Can you rekey a lock if it's part of a restricted-key system?

Often, yes, but the answer depends on the brand and how the system was set up. Some restricted-key hardware has parts and keyways that need to stay within the original system. If that's what your building uses, we'll identify it first and explain what can be rekeyed and what can't.
