Panic Bar Installation in Camden - common questions

How does panic bar installation work on a storefront in Camden?

We start by checking the door, frame, and existing lock hardware, then choose a panic device that fits the opening and the way the business uses it. After installation, we test latch function, door closure, and exit operation so the opening works as intended and is ready for inspection.

What should I have ready before you install a panic bar at my Camden business?

Have the door unlocked and the area around it clear. If you're a tenant, it helps to have landlord approval or any building rules that affect the opening. We also need to know whether the door is part of a fire exit, whether it has a closer, and if there's alarm or access control tied to it.

Can an old steel door on Route 13 still take a panic bar?

Often, yes, but old doors can need extra work. We check the thickness of the door, frame alignment, and whether the surface is solid enough for the hardware. If the door has prior patching or uneven wear, we may need reinforcement or a different device so it operates correctly.

Should I choose a touch bar or a crossbar for my restaurant exit?

It depends on the door, the code requirements, and how your staff uses the opening. A touch bar is common on many commercial exits because it's easy to use under pressure. We look at the door type, traffic, and any added hardware before recommending what will fit best.

What if my exit door already has a lock but no panic hardware?

That's a common setup we can evaluate. Some locks can stay if they don't interfere with the exit device, while others need to be replaced or reworked. The important part is that the door opens easily from the inside and still secures properly when closed.
