Repair, Rekey, or Replace

When a building changes hands in the key system because of staff turnover or a missing master, we start by looking at what the locks are actually doing now. If the hardware is solid and the problem is control over who can open it, rekeying is usually the cleanest move. We change the pins so old keys no longer work, then set the doors up around the keys you want to keep in circulation. If a lock binds because of wear, a loose cylinder, broken springs, or a door that has settled, repair may be the first step before any rekeying makes sense. In the Historic District, we see that a lot with older mortise and rim locks that have lived through years of shifting wood and painted-over hardware.

Replacement comes in when the lock is worn past practical repair, the keyway is damaged, or the existing hardware no longer matches how the property is managed. That can happen in a storefront off US-13 or in a multi-door office where one lost master could put too much at risk. We look at the condition of each lock, the type of key control you need, and whether the doors should be brought onto a more consistent system. The point is not to swap hardware just because a key went missing. It's to choose the least disruptive option that still protects the building, the staff, and the access you want to keep. Sometimes that means one repaired lock, several rekeyed doors, and one or two replacements where the hardware has already reached the end of the road.

Commercial Lock Rekeying in New Castle - common questions

How does commercial rekeying work for a shop or office in New Castle?

We take the existing lock cylinders apart, change the internal pinning, and cut new keys to match the new setup. The old keys stop operating the locks. If the building has several doors, we can also arrange them so one key works some doors while another key is limited to specific areas.

What should we have ready before you come to rekey our building?

Have a list of every door that needs to be changed and note which keys still need to work after the job. If you have a master key system, bring any existing key records or building notes. It also helps to know about back doors, tenant spaces, and any locks that have been sticking or acting up.

If we lost a master key, does rekeying really protect the property?

It does, as long as every lock controlled by that key is included in the rekey. The old master and any copies tied to it will no longer operate the changed cylinders. If some doors are left out, those locks still remain vulnerable, so we'll talk through the full keying plan before starting.

Should we rekey or replace the locks on an older New Castle building?

Rekeying is usually the first option if the hardware is still sound. That matters in older buildings where the locks may be original or have been adapted over time. If a cylinder is badly worn, damaged, or no longer serviceable, replacement makes more sense than forcing a bad lock to keep going.

Can you rekey a building that has mixed old and newer locks?

Often, yes. That's common in New Castle, where a property might have an older front entry and newer interior or rear doors. We'll identify which locks can be rekeyed, which ones need parts, and whether the whole place can be set up under one key or a small key system.
