Door Closer Installation in Glasgow - common questions

How do you choose the right door closer for a shop entrance in Glasgow?

We look at the door material, width, weight, hinge type, and how much use the opening gets. A light interior office door needs a different closer than a heavy storefront door. We also check whether the door needs hold-open hardware, delayed action, or a setup that works better for staff and customers moving through all day.

What should we have ready before you install a closer at our building?

It helps to know which door is giving trouble and what it's doing now, like slamming, dragging, or not latching. If there are access rules, fire-door concerns, or tenant hours to work around, tell us upfront. We can usually handle the rest on site, but the clearer the setup, the cleaner the install.

Can a door closer make a fire door unsafe if it's set wrong?

Yes. If a fire door doesn't close and latch reliably, that's a problem. A closer that's too weak, too strong, or badly adjusted can leave the door ajar or make it hard to close. We install and tune closers so the door closes under control and latches the way it should for daily use.

Should we repair the old closer or replace it with a new one?

If the closer is leaking, binding, or no longer holding adjustment, replacement is usually the better path. If the issue is mainly alignment or loose hardware, a repair may be enough. We compare the door, frame, and closer body before recommending a direction, because forcing the wrong fix usually brings the same problem back.

Can you install a closer on a door that's been enlarged or patched over the years?

Often, yes, but patched doors need a close look first. Old holes, uneven metal, added kick plates, or a frame that's been modified can affect where the closer mounts and how it performs. We work with the actual condition of the opening and adjust the hardware layout so the door closes cleanly and latches.
