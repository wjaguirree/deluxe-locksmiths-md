Lock Rekeying in Forest Hill - common questions

If we just bought a house in Forest Hill, should we rekey the locks or replace them?

Rekeying is usually the first thing we'd look at after a move if the hardware is in good shape. It changes which key works without swapping out the lock body. Replacement makes more sense when the lock is worn out, damaged, or not the style you want on the door.

What should we have ready before you come to rekey our doors?

Have the doors you want changed identified and make sure someone can give us access to the locks. If you want multiple doors matched to one key, tell us that up front. If there are builder locks, deadbolts, or keyed knobs from different manufacturers, that helps us plan the work cleanly.

Can old keys still work after a rekey if someone kept a copy?

No, not if the rekey is done correctly and all the affected cylinders are changed to a new key pattern. Any old copy should stop working on those locks. If you're worried about spare keys from a contractor, a roommate, or a previous owner, rekeying is the right reset.

Should we rekey every lock or only the front door?

That depends on how the house is used. Many people choose the front door, garage entry, and any door that gives direct access to the living space. If side doors, basement doors, or a back entry are part of daily access, it usually makes sense to include them so the whole house is consistent.

What if one of our locks was installed by the builder and doesn't match the others?

That's common in newer homes. We can often rekey mismatched locks so one key works across the doors you choose, as long as the lock type supports it and the hardware is still in usable condition. If a lock is a poor fit or too worn, we'll let you know that before doing anything unnecessary.
