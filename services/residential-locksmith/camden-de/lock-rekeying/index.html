Lock Rekeying in Camden - common questions

If I just moved to Camden, do I need to rekey every door lock right away?

Usually, yes, if you want to control who can still get in. Rekeying is a common first step after a move because you don't know how many copies of the old key are out there. A locksmith can rekey the locks you want to keep and leave any hardware that's still in good shape.

What should I have ready before a rekeying job at my house?

It helps to have every door you want included in mind, plus any keys you still have. If some locks are different brands or have been replaced at different times, say that up front. If you can point out a lock that sticks or a key that feels rough, that can save trouble during the job.

Can a rekey solve a lock that's already hard to turn on the older streets off Main Street?

Sometimes, but not always. Rekeying changes the key pattern inside the cylinder; it does not fix worn springs, bent parts, or a damaged lock body. If the lock is still structurally sound, rekeying may be enough. If the hardware is failing, repair or replacement may be the better answer.

Should I rekey or replace if I want one key for the front and back doors?

If the existing locks are compatible and in decent shape, rekeying is usually the cleaner choice. It lets the same key work on multiple locks without changing the hardware. If the locks are different models, badly worn, or missing parts, replacement may be needed on one or more doors.

Can every lock in a Camden house be rekeyed the same way?

Not always. Most standard residential deadbolts and knob locks can be rekeyed, but some older or specialty locks use different parts, and some damaged cylinders won't take a new key set well. A locksmith can check each lock and tell you which ones can be matched together and which ones need a different fix.
