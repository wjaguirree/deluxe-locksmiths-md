Lock Rekeying in Claymont - common questions

How does lock rekeying work on a house in Claymont?

We take the lock cylinder apart, change the internal pins, and cut new keys to match the new setting. The old key no longer works. This is useful after a move or when you want one key to fit several exterior doors without changing the whole lock.

What should I have ready before you come rekey the locks?

Have the doors accessible and make sure you know which locks you want changed. If there are extra keys still floating around, gather them up too. If the house has separate front, side, and back entries, it helps to point out which ones should match and which ones should stay separate.

Can a painted-over old lock still be rekeyed?

Often, yes. We see that on older Claymont homes where the hardware has been painted more than once. Sometimes the lock can still be serviced cleanly. Other times the paint or wear has gone too far, and replacement makes more sense. We can tell you what the lock will support once we're there.

Should I rekey the locks or replace them after buying a home in Claymont?

Rekeying is usually the first thing to consider if the hardware is in decent shape and you just want control over old keys. Replacement makes more sense if the lock is damaged, mismatched, or worn out. We can look at the doors and explain which choice fits each one.

What if my Claymont house has different locks on the front and back doors?

That's common. We can often rekey different locks to work with one key, as long as the hardware uses compatible parts. If one lock is a different type or too worn to match, we'll say so plainly. Mixed hardware doesn't rule out rekeying, but it can affect how the keys are set up.
