Lock Rekeying in Dover - common questions

If I just moved into a house in Dover, should I rekey every lock or only the front door?

Usually every exterior door should be rekeyed, not just the front. Back doors, side entries, and garage-to-house locks all matter. If one old key still works anywhere, that's a gap you probably don't want after a move. A locksmith can look at the hardware and key the locks so they work from the same set if that makes sense.

What should I have ready before someone comes to rekey my locks?

Have all the keys you know about, plus a quick list of which doors are involved. If you're in a rental or a house with previous owners, it helps to know whether there are any locks that should stay separate. Clear access to the doors, and tell the locksmith if anything is sticking, loose, or hard to turn.

My landlord changed some locks before I moved in. How do I know if they were actually rekeyed?

You can't always tell by looking. A lock can keep the same housing and still be rekeyed inside. The practical question is whether any old keys still open it. If you're unsure, ask for the locks to be checked and keyed to a fresh set so you know exactly what works.

Should I rekey or replace the lock if the house near The Green is older?

If the hardware is solid and the lock just needs new key control, rekeying is often the better move. If the latch is worn, the key is hard to turn, or parts are damaged, replacement may make more sense. Older homes can have good hardware that still needs attention before it's ready to keep using.

Can you rekey a rental when the new tenant is already moving in that day?

Yes, that's a common reason to do it. The key issue is having access to the lock and a clear decision on which doors should use the same key. If there are multiple exterior entries or an added deadbolt, it helps to know that up front so the hardware can be handled in one pass.
