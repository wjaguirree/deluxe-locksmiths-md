Locksmith in Charlestown - common questions

If my house key stops turning in Charlestown, should I keep trying it?

No. If a key won't turn, forcing it can snap the key or worsen the damage inside the cylinder. Stop using that key, try any spare you trust, and look for signs that the door is binding or the lock is loose. If the key still won't move, the lock likely needs service or replacement.

What should I have ready if I'm locked out near the waterfront?

Have proof that you live or work there, plus the exact address and a phone number that reaches you. If you can safely do so, note the type of lock on the door, gate, or storage area. Don't pry the door or try to pick the lock, because that can make the repair more involved.

My marina padlock is rusted shut. Is it better to cut it off or try to save it?

If the padlock protects something you need to keep secure, don't cut it until you know it can be replaced without leaving the property exposed. If it's a weathered lock and the key no longer works, a locksmith can tell whether cleaning, freeing the shackle, or replacing the lock is the better route.

Should I rekey my Charlestown home or replace the locks after a key is lost?

Rekeying makes sense when the lock body is in good shape and you want the old key to stop working. Replacement is better if the hardware is worn, corroded, or damaged. If more than one door uses the same key, ask about doing them together so the set stays consistent.

Can a broken mailbox or gate lock be repaired, or does it usually need new hardware?

Sometimes it can be repaired if the latch, housing, or cylinder is still sound. If the lock is bent, corroded, or missing key parts, replacement is usually the cleaner fix. The condition of the mounting surface matters too, because a good lock won't work well on a loose box or sagging gate.
